# Mastercard Excessive Chargeback Program (ECP) — Guide

**Source**: https://chargebacks911.com/mastercard-chargebacks/mastercard-excessive-fraud-chargeback-monitoring-programs/mastercard-ecm-program-thresholds-tiers/

## Program Tiers

### ECM (Excessive Chargeback Merchant)
- Threshold: **150–299 bps** AND **100–299 chargebacks/month**
- Calculation: `bps = (monthly_chargebacks / previous_month_settled_tx) × 10,000`

### HECM (High Excessive Chargeback Merchant)
- Threshold: **≥300 bps** AND **≥300 chargebacks/month**

## Calculation Reference

For Merchant B:
- Monthly chargebacks: 185
- Previous month settled transactions: 10,000
- Chargeback ratio: 185/10,000 × 10,000 = **185.00 bps**
- Program tier: **ECM** (150–299 bps range)
