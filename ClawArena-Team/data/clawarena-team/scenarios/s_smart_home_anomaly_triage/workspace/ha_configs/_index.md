# Home Assistant Configurations

| File | Description |
|------|-------------|
| `configuration.yaml` | Main HA configuration |
| `automations.yaml` | Automation rules (security / lighting / climate) |
| `scenes.yaml` | Scene definitions |
| `device_tracker.yaml` | Occupant presence tracking |
| `camera.yaml` | Camera stream configurations |
| `sensor.yaml` | Sensor entity definitions |
| `notify.yaml` | Notification channel setup |
| `input_boolean.yaml` | Toggle helpers |
| `scripts.yaml` | Reusable script definitions |
| `channel_plan.yaml` | Zigbee/Z-wave channel allocation policy |
