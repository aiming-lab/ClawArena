# Calendar Directory

ICS calendar files for the Chen residence.

| File | Description |
|------|-------------|
| `household_calendar.ics` | Family events, travel, appointments |
| `nanny_schedule.ics` | Ana Reyes scheduled working windows (authoritative) |
| `maintenance_windows.ics` | IntegraTech OTA and service windows |

The `nanny_schedule.ics` file is the authoritative record of Ana Reyes's
approved presence windows. It is maintained by AllCare Staffing and synced
to the household calendar. For any timing discrepancy, the ICS record takes
precedence over informal SMS communications.
