GIS Change Detection Reference Standards — Internal Working Document
Prepared by: GIS Analytics Division | Version: 3.2 | Date: 2025-11-01

Section 1: Remote Sensing Change Detection Methodology

Change detection in agricultural parcels relies on multi-temporal satellite
imagery acquired under comparable atmospheric and phenological conditions.
The following methodological framework applies to all boundary dispute analyses
conducted by this division.

1.1 Image Pre-processing
All imagery must undergo atmospheric correction (FLAASH or QUAC algorithm)
prior to change detection analysis. Geometric registration must achieve
sub-pixel accuracy (<= 0.5 pixel RMS error) relative to a reference dataset.
Cloud masking: scenes with >5% cloud cover over the target parcel are rejected.

1.2 Change Detection Algorithms
Primary: Normalized Difference Vegetation Index (NDVI) differencing
  NDVI = (NIR - Red) / (NIR + Red)
  Delta_NDVI threshold for agricultural land conversion: 0.15
Secondary: Object-Based Image Analysis (OBIA) for boundary delineation
  Segmentation scale: 50-80 (Multiresolution Segmentation)
  Shape weight: 0.3 | Compactness: 0.5

1.3 Area Calculation
Area is calculated in the projected coordinate system (CGCS2000 / Gauss-Kruger)
using pixel counting for raster analysis and polygon area for vector output.
Conversion factor: 1 pixel (3m GSD) = 0.0009 hectares
For area-7 ROI (240 x 220 pixels = 52,800 pixels): base area ~47.5 ha
Full parcel area from cadastral: 142.30 ha

Section 2: Accuracy Assessment Framework

2.1 Reference Data Requirements
Ground truth must include field-verified GNSS points with RTK accuracy
(horizontal: <=0.02m, vertical: <=0.05m). Minimum 20 boundary points
required for parcels between 100-200 hectares.

2.2 Tolerance Standards (Provincial Standard DB37/T 4122-2021)
Parcel size 0-50 ha:   tolerance 0.1 ha
Parcel size 50-200 ha: tolerance 0.5 ha  <-- applies to area-7
Parcel size >200 ha:   tolerance 1.0 ha

2.3 Cross-Validation Protocol
When satellite-derived area delta and GNSS-derived area delta differ by
less than the applicable tolerance, both measurements are considered
consistent. For area-7: tolerance = 0.5 ha.
Satellite delta: +18.4 ha | Survey delta: +18.1 ha | Difference: 0.3 ha
0.3 ha < 0.5 ha tolerance => CONSISTENT => proceed to boundary decision.

Section 3: Boundary Decision Framework

3.1 Decision Outcomes
accept_boundary_v2: Satellite and GNSS data consistent; delta >= 5 ha;
  required documentation complete; approve revised boundary.
reject: Inconsistency > tolerance; or documentation incomplete.
defer: Insufficient data; request additional survey.

3.2 Documentation Checklist
[ ] Dual-date satellite imagery (pre/post)
[ ] ROI metadata (scene IDs, acquisition dates, cloud cover)
[ ] Third-party GNSS survey within 90 days of T2
[ ] Legal boundary definition document (cadastral ref)
[ ] Cross-reference validation (satellite vs GNSS delta)
[ ] Boundary decision record with compliance signature

Section 4: Case Studies (Historical)

4.1 area-3 (2023): Delta +22.1 ha accepted after dual verification.
4.2 area-5 (2024): Delta +3.1 ha — below 5 ha threshold; rejected.
4.3 area-6 (2024): Survey inconsistency 1.2 ha > tolerance; deferred.

Section 5: Data Management

5.1 File Naming Convention
  Imagery: <scene_id>_<date>_<area_id>.<ext>
  Survey:  <type>_<date>_<area_id>.<ext>
  Output:  <analysis_type>_<date>_<area_id>.<ext>

5.2 Retention Policy
All primary data (imagery, survey files) retained 10 years.
Analysis outputs retained 5 years.
Decision records retained permanently.
