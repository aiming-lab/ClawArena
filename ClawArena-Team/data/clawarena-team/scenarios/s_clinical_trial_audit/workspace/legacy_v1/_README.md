# Legacy Data Archive — NT-4400 Phase I (2024)

**ARCHIVED — NOT APPLICABLE TO CURRENT NT-7701 PHASE II AUDIT**

This directory contains legacy data from the 2024 Phase I study of NT-7701
precursor compound NT-4400. The NT-4400 study was completed in 2024 and the
data was archived on 2025-01-15.

**This data is NOT applicable to the current Phase II NT-7701 clinical trial
data integrity audit.** Subject IDs, site assignments, IRB numbers, and all
safety data in this directory relate exclusively to the NT-4400 Phase I
compound and have no relationship to NT-7701 Phase II findings.

If you are working on the NT-7701 Phase II audit (reference NT7701-AUDIT-2026-001),
do not use any data or documents from this `legacy_v1/` directory. The IRB
approval number for the NT-4400 Phase I study (IRB-2024-NT4400-001) is different
from the NT-7701 Phase II IRB approval number and must not be cited in NT-7701
deliverables.
