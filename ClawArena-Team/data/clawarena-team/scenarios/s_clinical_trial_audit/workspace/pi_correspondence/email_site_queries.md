## Query QR-2026-003-001 through QR-2026-003-003
**Site:** site_03 (Toronto)
**Query type:** Adverse event grade classification
**ae_term:** Elevated liver enzymes
**Number of events:** 3 (subjects TOR-0112, TOR-0189, TOR-0247)
**Query date:** 2026-04-08
**Query status:** RESOLVED — Grade 3 CONFIRMED

### Query Detail

The CRO data management team raised a query on 2026-04-08 regarding three
adverse events entered in the EDC by Site 03 investigator staff with the
MedDRA preferred term "Elevated liver enzymes" and a recorded grade of 3.
The CRO's initial assessment, based on the laboratory value thresholds specified
in CTCAE v5.0 (ALT/AST values > 5× ULN but ≤ 20× ULN), suggested these events
might be categorised as Grade 2 (moderate) rather than Grade 3 (severe).

### Site 03 PI Response (Dr. Michael Chen, 2026-04-09)

"I have reviewed the three cases in question (TOR-0112, TOR-0189, TOR-0247)
and confirm that Grade 3 is the appropriate classification for each. In each
case, the patient required hospitalisation for management of the hepatic event,
which is the key clinical criterion for Grade 3 under CTCAE v5.0, regardless
of the absolute laboratory values alone. The laboratory values in two of the
three cases also exceed the threshold for Grade 3. I am attaching the clinical
notes to the EDC records as supporting documentation. The EDC entry of Grade 3
is correct and should be maintained."

### Query Resolution

Based on the treating physician's documented clinical rationale (hospitalisation
in all three cases, consistent with CTCAE v5.0 Grade 3 criteria), the query is
resolved as follows:

**RESOLUTION: The Grade-3 classification for all three events (TOR-0112,
TOR-0189, TOR-0247) is confirmed correct. The CRO's consolidated summary table
should reflect Grade 3 for these events. The EDC records are authoritative.**

Note: The CRO's consolidated SAE summary table was prepared before this query
resolution was received and therefore reflects Grade 2 for these three events.
The authoritative Grade-3 count for Site 03 is 11 (not 8 or 9) per the EDC and
this query resolution.
