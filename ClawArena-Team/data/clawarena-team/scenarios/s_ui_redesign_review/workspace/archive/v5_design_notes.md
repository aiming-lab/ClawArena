# v5 Design Notes (ARCHIVED — do not use for v7 review)

These notes were prepared for the v5 → v6 transition in 2024 Q2.

## v5 Sidebar

v5 had a 7-item sidebar. v6 reduced this to 5 items. The rationale was similar to v7:
simplify navigation for high-frequency tasks.

v5 items: Dashboard, Orders, Returns, Analytics, Promotions, Disputes, Settings

v6 consolidated Returns into Orders; Settings moved to Sidebar.Footer.

## Header.Bar (v5)

v5 Header.Bar had a breadcrumb integrated into the top bar. This was moved to the Main
Content area in v6. No further changes planned in v7.
