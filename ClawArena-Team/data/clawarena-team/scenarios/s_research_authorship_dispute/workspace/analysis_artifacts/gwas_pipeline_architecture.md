## Overview

The cross-ancestry GWAS pipeline consists of seven sequential processing stages, each implemented
as a modular Python/PLINK2/R workflow. The pipeline is reproducible via snakemake and all
intermediate outputs are checksummed for integrity verification.

## Stage 1 — Cohort Ingestion

Raw cohort-level GWAS summary statistics are ingested from four biobanks (UKBB, FinnGen, BBJ,
Toronto Biobank). Each cohort file is validated against a reference manifest specifying expected
variant counts, allele frequency ranges, and effect-size distributions.

## Stage 2 — Quality Control and Variant Filtering

Variants are filtered using INFO score > 0.8, MAF > 0.01, and per-cohort call rate > 0.98.
Palindromic SNPs (A/T and C/G) at intermediate frequency are removed. Duplicate variants are
resolved by retaining the entry with the higher imputation INFO score.

## Stage 3 — Harmonised Dataset Integration

At Stage 3, the pipeline ingests the harmonized intermediate dataset (`harmonized_gwas_v2/`)
generated by the harmonisation module. This dataset contains the cross-cohort harmonised
summary statistics with aligned allele coding, standardised effect-size estimates, and
provenance metadata. Stage 3 represents the first point at which cross-cohort data are combined
into a unified analysis dataset.
