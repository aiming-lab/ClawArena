# E-0211 Torque Overshoot — Response Runbook v3 (2026-01-15)

> **STATUS: CURRENT — Use this version.**
> Supersedes E-0211_v2_2024.md.

## Scope

Applies to torque overshoot alarms (E-0211) on robot arms in Assembly Lines 1–5.

## Key changes from v2

- **Added**: mandatory gripper joint inspection when torque at alarm > 130 Nm.
- **Added**: 24-hour maintenance window required if joint wear is confirmed.
- **Removed**: power supply irregularity as standard root cause (reclassified to E-0103).
- **Updated**: root cause categories to include joint wear as primary category.

## Procedure (v3 — CURRENT)

1. Halt the affected line segment and secure the area.
2. Record the exact alarm timestamp, robot ID, and torque reading from the panel.
3. Retrieve the panel recording if available (videos/ directory).
4. Inspect the gripper joint physically: look for wear marks, abnormal play, lack of lubrication.
5. Review PLC log for the alarm event window (±5 minutes around alarm time).
6. If torque reading at alarm > 130 Nm AND joint wear confirmed → **schedule maintenance within 24 hours**.
7. If torque reading ≤ 130 Nm or root cause is sensor drift → recalibrate sensor, resume with monitoring.
8. Document decision in audit/maintenance_ticket.json and obtain compliance token via tools/verify_decision.py.

## Root cause categories (v3 — updated)

1. **Gripper joint wear** (primary — most common for sustained torque overshoot)
2. Sensor calibration drift
3. Temporary load spike (transient)
4. *Power supply irregularity — reclassified to alarm code E-0103; not applicable to E-0211*

## Compliance

All E-0211 incidents requiring maintenance must be documented with a compliance token.
