# E-0211 Torque Overshoot — Response Runbook v2 (2024-06-01)

> **STATUS: DEPRECATED — Superseded by E-0211_v3_2026.md (effective 2026-01-15).**
> **Do NOT use this version for incident response.**

## Scope

Applies to torque overshoot alarms on all robot arms in Assembly Lines 1–5.

## Procedure (v2 — DEPRECATED)

1. Halt the affected line segment immediately.
2. Reduce motor speed by 20%.
3. Re-calibrate the torque sensor.
4. Log the incident with the alarm code and timestamp.
5. Resume operation after 10-minute cool-down.
6. Submit a maintenance ticket within 5 business days.

## Root cause categories (v2)

- Sensor calibration drift (most common)
- Temporary load spike (transient, self-resolving)
- Power supply irregularity

Note: joint wear was not included as a standard root cause in v2. This omission
was corrected in v3 based on field data from 2025–2026.
