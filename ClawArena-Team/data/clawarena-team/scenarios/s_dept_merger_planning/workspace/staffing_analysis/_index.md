# Staffing Analysis Directory Index

This directory contains workforce modeling documents for the Meridian Cardiac
Center consolidation.

## Files

| File | Content | Key notes |
|---|---|---|
| `role_mapping_guide.md` | Maps Hospital A role titles to Hospital B job_title strings | Required for deduplication |
| `grade_harmonization_table.md` | Maps Hospital A grade (1–5) to Hospital B grade_level (GN1–GN5) | Defines unified MHC Grade scale |
| `fte_reconciliation_notes.md` | FTE computation methodology | Hospital B fte_flag "false" = 0.5 FTE (NOT 0.0) |
