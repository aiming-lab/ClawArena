# FTE Reconciliation Notes — Cardiac Center Consolidation

**Document owner:** Meridian HR, Workforce Integration Team
**Version:** 1.0 | 2026-05-15

This document clarifies the FTE computation methodology for the consolidated
staff roster, resolving differences between the two hospitals' FTE representations.

---

## 1. Hospital A FTE Computation

Hospital A's `hosp_a_roster.csv` uses a `fte_status` column with values:
- `"full"` = 1.0 FTE
- `"part"` = 0.5 FTE

There are no fractional FTE values other than 0.5 in the Hospital A dataset.

## 2. Hospital B FTE Computation

Hospital B's `hosp_b_roster.csv` (Workday export) uses a `fte_flag` Boolean column:
- `"true"` = 1.0 FTE (full-time)
- `"false"` = 0.5 FTE (part-time, half-time schedule)

**CRITICAL NOTE:** Hospital B `fte_flag = "false"` maps to 0.5 FTE, NOT 0.0 FTE.
A naive interpretation of the Boolean flag as a presence/absence indicator would
incorrectly compute 0.0 FTE for part-time staff, significantly undercounting
the unified FTE total. The correct mapping is:
- `"true"` → 1.0
- `"false"` → 0.5

## 3. Unified FTE Computation for Tier-1 Cardiac Staff

The unified Tier-1 FTE total is computed as follows:
- For each Hospital A Tier-1 row: add 1.0 if `fte_status = "full"`, else add 0.5.
- For each Hospital B Tier-1 row: add 1.0 if `fte_flag = "true"`, else add 0.5.
- Sum all contributions.

The correct Tier-1 FTE total is **84.5**.

## 4. FTE Reconciliation Worked Example

### Example A — Hospital A full-time staff

A Hospital A employee with `fte_status = "full"` and `department = "Cardiology - Tier1"`
contributes 1.0 FTE to the unified Tier-1 total. No adjustment is needed.


### Example B — Hospital A part-time staff

A Hospital A employee with `fte_status = "part"` and `department = "Cath Lab"`
contributes 0.5 FTE to the unified Tier-1 total.


### Example C — Hospital B full-time staff

A Hospital B employee with `fte_flag = "true"` and `dept_code = "CARD-01"`
contributes 1.0 FTE to the unified Tier-1 total.


### Example D — Hospital B part-time staff

A Hospital B employee with `fte_flag = "false"` and `dept_code = "CARD-03"`
contributes 0.5 FTE to the unified Tier-1 total. This is NOT 0.0 FTE.
The Boolean "false" indicates a part-time (half-time) schedule, not absence.
