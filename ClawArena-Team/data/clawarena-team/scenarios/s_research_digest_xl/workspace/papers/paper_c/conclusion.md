# 6. Conclusion

We presented FaithRAG, a constrained decoding framework that addresses the context-drift failure mode of retrieval-augmented generation by penalising tokens that are not attributable to retrieved passages. Combined with standard dense retrieval, FaithRAG delivers a 28% absolute improvement in factual accuracy on TruthfulQA and FActScore and a 41% relative reduction in hallucination rate, at a modest fluency cost that practitioners can tune via the constraint strength `λ`. The system composes with any existing RAG pipeline, requires no changes to the generator's parameters, and is released as open source alongside both full-size and distilled attribution scorers. We hope FaithRAG makes faithful generation cheap enough to be the default rather than the premium tier in production deployments of language models.
