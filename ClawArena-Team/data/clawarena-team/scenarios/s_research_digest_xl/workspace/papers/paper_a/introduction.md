# 1. Introduction

Modern transformer-based language models derive much of their expressive power from the self-attention mechanism, which allows every token in a sequence to attend to every other token. While this dense connectivity is a major source of representational flexibility, it carries a well-known cost: both compute and memory scale quadratically with the sequence length. For a model with hidden size `d` operating on a sequence of length `n`, the attention matrix alone occupies `O(n^2)` memory, and the key/value cache that supports autoregressive decoding grows linearly with both `n` and the number of layers. On contemporary 70B-parameter architectures, this quadratic factor dominates the total VRAM budget once context length exceeds roughly 16k tokens, forcing practitioners to shard inference across multiple accelerators or to truncate prompts in ways that materially hurt application quality.

This memory wall has motivated a substantial body of work on approximate attention. Existing approaches fall into three broad families. Static-sparsity methods such as Longformer and BigBird hardcode local windows and a small set of global tokens; they offer predictable memory profiles but cannot adapt the receptive field per query. Low-rank methods such as Linformer and Performer project keys and values into a fixed-dimensional subspace, which keeps memory bounded but introduces a multiplicative approximation error that compounds across layers. Finally, learned-sparsity methods such as Routing Transformers and Reformer cluster tokens via locality-sensitive hashing or k-means, achieving sub-quadratic complexity at the cost of expensive clustering kernels and noisy gradients. None of these approaches has been able to deliver large memory savings, training stability, and inference throughput simultaneously.

We approach the problem from a different angle. Our central observation is that the *empirical* attention distribution in trained transformer models is highly non-uniform and surprisingly local: across a representative sample of forty pretrained checkpoints we surveyed, more than 92% of the attention mass for any given query is captured by fewer than 12% of the keys, and the identity of those keys is well-predicted by a small set of geometric and semantic features. This suggests that a learned, query-dependent sparsity mask should be able to recover most of the quality of dense attention while paying only a fraction of the memory cost — provided the mask itself can be computed cheaply.

We instantiate this insight in **SparseFormer**, a transformer variant in which each query token is paired with an *adaptive locality prior* — a lightweight module that predicts, in a single feed-forward step, which keys are likely to be relevant. The prior is conditioned on the query embedding, the token's positional index, and a compact summary of the layer's input distribution. SparseFormer then materialises only the selected key/value pairs, applies standard scaled-dot-product attention on this compact set, and skips the remaining computation entirely. Because the mask is generated per query rather than per layer, the receptive field can be wide where the model needs broad context and tight where local information suffices.

The contribution of this paper is threefold. First, we present the architecture and training procedure for SparseFormer in detail, including the gradient estimator that allows us to train the discrete sparsity mask end-to-end. Second, we prove an upper bound on the approximation error of SparseFormer attention relative to dense attention, expressed in terms of the entropy of the empirical attention distribution; this bound tightens automatically as the model learns more peaked distributions, providing a clean theoretical explanation for SparseFormer's strong empirical performance. Third, we report a comprehensive empirical study covering pretraining stability, downstream task accuracy across seven benchmarks, end-to-end inference latency, and VRAM utilisation under realistic deployment conditions.

The remainder of the paper is organised as follows. Section 2 surveys related work in efficient attention and motivates the design choices behind SparseFormer. Section 3 describes the architecture, training objective, and mask gradient estimator. Section 4 presents experimental results on memory, throughput, and downstream task quality, including ablations isolating the contribution of each architectural component. Section 5 discusses limitations and practical considerations for deployment, and Section 6 concludes with directions for future work, including extensions to multimodal inputs and hardware-aware sparsity patterns.
