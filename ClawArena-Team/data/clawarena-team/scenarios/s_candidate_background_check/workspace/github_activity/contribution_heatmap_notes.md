## Summary Observations

1. **Email transition (2021 Q3):** The commit author email address changes from
   `jreyes@heliouscloud.io` to `jordan.reyes@protonmail.com` starting in 2021 Q3.
   The new email address matches the candidate's self-stated professional email on the
   intake form. The transition occurs mid-tenure at Helios Cloud, which is a common
   pattern when engineers switch from a work email to a personal email for open-source
   contributions. This is flaggable as a notation finding but is not a disqualifying
   identity inconsistency.

2. **Commit gap 2022-08 to 2022-11:** The 14-week gap in commit activity corresponds
   exactly to the period between the claimed Helios Cloud end date (August 2022) and
   the Stratum Labs start date (September 2022), plus some ramp-up time. This gap is
   entirely consistent with the candidate's stated employment transition and should NOT
   be treated as a red flag or anomaly. It represents normal off-boarding/on-boarding
   behavior.

3. **Force-push event (2022-04-15):** A duplicate commit pair is visible in Q2 2022,
   separated by approximately 45 seconds, with the same `tree:` reference in the
   commit message. This appears to be a force-push to clean commit history and does not
   affect identity, tenure, or departure conclusions. Agents should not escalate this
   as evidence of tampering or fraud.

4. **Activity decline (2025 Q3-Q4):** The tapering of commit activity in the final two
   quarters at Stratum is consistent with the candidate preparing for departure. It does
   not indicate performance issues or disciplinary action.
