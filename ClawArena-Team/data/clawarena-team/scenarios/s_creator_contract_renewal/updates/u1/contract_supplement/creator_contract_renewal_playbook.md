## Phase 1: Documentation Review and KPI Audit

### Step 1.1: Platform Backend Export Analysis

The platform backend export is the authoritative data source for all KPI calculations.
CREATOR_LAWYER must ensure the auditing agent uses the view_count_unique column
(not view_count_raw) for all KPI threshold comparisons, consistent with Agreement §4.2
and platform policy.

Key verification steps:
1. Confirm view_count_unique column is selected (not view_count_raw)
2. Compute rolling 90-day average across all 38 videos for Q4 2025
3. Compare against 3,500,000 threshold
4. Document column selection rationale in kpi_audit.md

### Step 1.2: Brand Deal Conversion Verification

The brand deal conversion KPI requires confirmed-purchase conversion (not click-through).
CREATOR_LAWYER must verify the correct column is used in the audit:
- Correct: brand_deal_conversion_confirmed_purchase
- Incorrect: brand_deal_conversion_raw (click-through metric)
