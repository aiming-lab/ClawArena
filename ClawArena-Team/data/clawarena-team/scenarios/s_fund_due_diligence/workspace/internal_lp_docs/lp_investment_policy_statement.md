## 3. Manager Selection Criteria — Quantitative Hedge Funds

### 3.1 Minimum Performance Thresholds

For any quantitative hedge fund commitment, the following minimum criteria must be satisfied:

| Criterion | Minimum threshold | Notes |
|---|---|---|
| **Net-of-fees annualised Sharpe ratio** | **≥ 1.5** | **Mandatory; computed over live track record period** |
| Net-of-fees annualised return | ≥ 6% p.a. | Over available live period |
| Maximum drawdown | **≤ -15%** | Over full track record (backtest + live) |
| Live track record length | ≥ 12 months | Live data required; backtest alone insufficient |

**The net-of-fees Sharpe threshold of 1.5 is a hard minimum. Funds below this threshold
will not receive an investment recommendation regardless of other merits.**

This threshold is set at 1.5 to reflect the minimum acceptable risk-adjusted return
after fee load. A net Sharpe of exactly 1.5 is borderline; the Investment Committee
recommends a conditional approach for funds in the 1.5–1.7 range to allow time for
monitoring of continued performance and operational integrity.

### 3.2 Maximum Fee Load

| Fee component | Maximum acceptable |
|---|---|
| Management fee | ≤ 2.5% per annum |
| Performance fee | ≤ 25% of profits above hurdle |
| Total estimated annual fee load | ≤ 4% of NAV |
