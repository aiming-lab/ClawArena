# Archived Materials — Apex Fund II Strategy Version 0 (Pre-Pivot, 2017)

**ARCHIVED — DO NOT USE FOR CURRENT DD**

This directory contains materials from Apex Capital Management Fund II strategy version 0,
which predates the current fund strategy. These materials were archived following the
strategy pivot in late 2017 and are retained for historical reference only.

**These materials are NOT applicable to the current Apex Capital Management Fund II
evaluation. Do not cite any figures from these files in the DD analysis.**

Strategy v0 used a fundamentally different signal construction approach (discretionary
fundamental screens combined with quantitative filters) that was superseded by the current
fully systematic multi-factor approach. The performance figures in these archived materials
(e.g., Sharpe 0.83) relate to the pre-pivot strategy and have no bearing on Fund II's
current performance.
