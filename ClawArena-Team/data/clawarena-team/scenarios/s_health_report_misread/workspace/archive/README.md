# archive/ — Historical Checkup Records

This directory contains archived annual checkup records from prior years.
These records are provided for longitudinal context only. The current-year
report (2026) is in `checkup_reports/`.

Files:
- `checkup_2023_summary.txt` — 2023 annual checkup summary (low priority)
- `checkup_2022_lab_export.csv` — 2022 lab export (low priority)
- `checkup_2021_notes.txt` — 2021 notes
