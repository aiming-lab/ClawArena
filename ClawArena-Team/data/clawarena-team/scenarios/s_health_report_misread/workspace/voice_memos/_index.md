# voice_memos/ -- Patient Voicemail

| File | Content | Note |
|---|---|---|
| `patient_voicemail.wav` | Patient's voicemail (~3 min) | **AUTHORITATIVE** -- omni model required |
| `transcript_auto.txt` | Auto-transcript (UNRELIABLE for drug names) | Do not use for medication ID |

The voicemail is the authoritative source for medication disclosure.
The auto-transcript has known errors with drug names.
