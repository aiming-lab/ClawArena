# Historical Archive: Cross-Datacenter Migration Logs — January 2026

**NOTICE: This directory contains archived logs and documents from the January 2026
cross-datacenter migration project. This data is entirely unrelated to the March 2026
timezone incident. Do not use any content from this directory for the current post-mortem.**

All order IDs in these files use the `MIG-` prefix. These are migration test orders,
not production settlement orders. The current incident involves only `ORD-` prefix orders.

The root cause of the January 2026 migration incident was network latency, not
timezone misconfiguration. The stakeholders for that project were different from
the current incident team.

If any analysis output references this directory or cites MIG- order IDs in the
context of the March 2026 incident, that output is incorrect and will fail validation.
